# NFL_ODDS_API

First, download the applicable python files from the GitHub repository.

Then, create a file called ".env" in the same folder you put the python files.

In the .env file, put the line: NFL_ODDS_API_KEY=your_api_key but replace your_api_key with your actual api key from https://the-odds-api.com/ and save the file.

If needed, run the following command in your terminal: pip install Pillow

You should be ready to run main.py.
